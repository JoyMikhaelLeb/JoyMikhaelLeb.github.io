World Cup 2026 Predictor

Machine learning, full stack

Predicts World Cup match outcomes and full scoreline distributions. Tracks team strength with a custom ELO engine over 49,000+ international matches since 1872, adds rolling form features, then trains a logistic regression for win, draw and loss and two Poisson regressions for goals. Corrects for neutral venues by averaging both team orders and resolves knockout draws through extra time and penalties. The grid at the top of this page uses the same scoreline method.

Python, pandas, scikit-learn, SciPy, FastAPI, Next.js, TypeScript

Resume-to-JD Matching Agent

LLM pipeline

Scores resume PDFs against a job description with the Claude API. Each resume is parsed with pdfplumber, turned into a structured profile and scored on four dimensions using forced tool use validated by Pydantic. Includes prompt caching on the shared job description, an optional self-critique pass and an eval harness for testing probabilistic LLM output. Outputs ranked JSON plus a Markdown report.

Python, Anthropic API, Pydantic, pdfplumber, evals

Tasklet Support Agent

AI agent

A multi-turn support agent for a fictional B2B SaaS, built on native Claude tool use with no agent frameworks. The model picks from predefined query functions instead of writing SQL, and per-user data scoping is enforced in the service layer with tested defenses against injected IDs. Conversation state persists to SQLite. Ships with a CLI, a Streamlit UI and a React dashboard over FastAPI.

Python, Anthropic API, FastAPI, SQLite, Streamlit, React, pytest
